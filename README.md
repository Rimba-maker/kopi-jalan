# Kopi Jalan

Landing page Astro untuk konsep kedai kopi keliling. Titik singgah saat ini belum dikonfirmasi, harga berasal dari brief, dan foto adalah ilustrasi stok—bukan bukti operasi bisnis.

## Mulai membaca

1. [Panduan proyek](docs/README.md) — struktur kode, perintah, deployment, dan cara memperbarui jadwal dengan aman.
2. [Konteks produk](PRODUCT.md) — audiens, tujuan, serta batasan fakta dan kanal kontak.
3. [Sistem visual](DESIGN.md) — token, tipografi, komponen, dan aturan poster kopi jalanan.
4. [Brief landing page](.impeccable/surfaces/src-pages-index-astro.md) — keputusan khusus permukaan; bukti visual ada di `.impeccable/review/`.
5. [Arsip brief awal](docs/archive/README.md) — status dokumen lokal dan batas penggunaannya.

Panduan agen internal (`AGENTS.md`/`CLAUDE.md`) dan PRD awal di `docs/archive/211-kedai-kopi-keliling-mobile-PRD.md` hanya ada di workspace lokal karena sengaja diabaikan Git. Arsip PRD memuat contoh yang tidak boleh diperlakukan sebagai fakta bisnis.

## Jalankan

```sh
npm install
npm run dev
```

Gunakan `npm run build` untuk build statis. Detail preview, base path, dan pengelolaan proses ada di [panduan proyek](docs/README.md).
